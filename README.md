# EVERMIND

A personal AI study workspace. This first commit establishes the responsive onboarding and dashboard interface.

## Current build
- Mobile-first onboarding with optional schoolwork upload
- Multi-file selection and drag-and-drop
- Local file list with remove controls and a 15 MB per-file limit
- Skip path for students who want to start fresh
- Workspace preview with Overview, AI Tutor, Assignments, Study Room, Memory, and Settings navigation

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Important current limitations
This is the interface foundation only. Files are not uploaded or stored, accounts are not connected, and AI / Google Docs features are not active yet. The next implementation phase will add secure authentication, private file storage, and server-side AI integration. Never place provider API keys in browser code or commit them to this repository.

## Deployment
This is a static site and can be deployed from the repository root on a static hosting provider.
